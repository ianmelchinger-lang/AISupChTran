Skill practice

Locate the broken link

When an automated response goes wrong, “the AI decided” hides which step failed, and the fix depends on the step. The move that comes first is to find the link that first produced an output unfit for its job.

The four links

Signal
Says something changed.
Insight
Says what the change means for a specific order, component, or customer.
Recommendation
Selects a feasible response.
Action
Carries the response out and changes a record or an operating instruction.

Each link can fail on its own. To find the failure, ask two questions of every link. What did it produce? What did the next link need?

Move one assumption

The same flow can fail somewhere else. Keep the four links and the two questions, and change only what the first link reports.

What moved

The answer moved from the recommendation link to the signal link, and the missing check moved with it. The flow stayed the same. Only the first link’s output changed.

“The data was wrong” was the wrong reading of the first record, because the signal there was true. It is the right reading of the second, because the signal itself was unfit for its job. The labels data, rule, and AI do not locate a failure. Comparing what each link produced with what the next one needed does.
