Count each loss once

A decision map states value line by line, and several lines can claim one loss. Rule on each line first, so that every loss counts once, and only then read where the value concentrates.

You are the supply chain transformation lead at Sample Enterprise Goods. The decision map holds eleven value lines. Each states a range in USD millions a year, and some claim a loss that another line also claims. The senior vice president wants three priorities this quarter. Rule on each line, read what the leading entries hold, and mark the entry whose place depends on where its range falls.

Keep
The line stands as its own entry, and its range counts in full.
Merge into a cluster
Two decisions draw on one pool, and one input would fix both. They stand together as one entry, and the pool counts once. Name the line it merges into.
Strike as a duplicate
Another line’s decision already claims this loss, or this line only passes the loss along. The line leaves the count. Name the line that holds the loss.
Set aside
The value is in a unit other than USD a year. It stays out of the ordering, and nothing converts it.
Concentration set
The few entries, a cluster counting as one, that hold most of the retained value.
