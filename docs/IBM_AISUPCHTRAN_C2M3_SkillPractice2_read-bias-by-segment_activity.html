Skill practice · Forecast bias

Read bias by segment

An error measure tells you how far the forecast misses. It does not tell you which way. Signed error keeps the direction, and direction predicts where the cost lands: over-forecasts become write-offs, under-forecasts become cuts and deductions.

The situation

You are the supply chain transformation lead at Sample Enterprise Goods. You are setting the bias part of the measure set that will judge any change to the baseline forecast. Five rows from last year’s forecast report follow.

Sign convention on this report: forecast minus actual, as a percentage of actual. A positive number means the forecast ran high (over-forecast). A negative number means it ran low (under-forecast).

Band
The range of signed bias a segment may show before a forecasting change is judged to have failed there.
Protected segment
A segment whose breach stops the change, whatever else improves.

Five rows

For each row, choose the direction, where its cost lands, and how the measure set should treat it. Check when you are ready; the check runs again as you change answers.

Move one assumption: the sign convention

A second report on the same five rows arrives from another source. It calculates actual minus forecast, so a positive number now means the forecast ran low. Read the direction of each row again.
